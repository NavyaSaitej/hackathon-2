# Spec Kit — The Enterprise Swecha Cheatsheet (V5 Ultimate)

Welcome to the **Swecha Compliance Spec Kit**. This repository provides a rigorous, 10-step framework to govern autonomous AI agents and human developers alike, ensuring that the resulting codebase perfectly adheres to enterprise-grade compliance, PWA, and CI/CD standards.

## Initialization

To start a new project with this workflow:
1. Create your project directory.
2. Copy the `.speckit` folder into the project root.
3. Feed this `CHEATSHEET.md` to your AI agent.

## The 10-Step Autonomous Workflow

Agents and developers MUST follow this sequence strictly. Do not skip phases.

```text
Step 1  Initialize          Bootstrap environment and Swecha Compliance configs (GitLab CI, Docker, Linters).
Step 2  Constitution        Load `.speckit/constitution.md` to establish non-negotiable operational mandates.
Step 3  Specify             Draft `.speckit/templates/specify.md` (Focus solely on WHAT & WHY).
Step 4  Clarify             Run `.speckit/prompts/clarify.md` to interactively resolve ambiguities in the Spec.
Step 5  Checklist           Run `.speckit/prompts/checklist.md` to unit-test the Requirements for quantifiable rigor.
Step 6  Plan                Draft `.speckit/templates/plan.md` (Define the Tech Blueprint & Modular Architecture).
Step 7  Tasks               Draft `.speckit/templates/tasks.md` to break the plan into parallelizable tasks.
Step 8  Mega Audit          Run the "7-Agent Swecha Mega Audit" (see below) before approving implementation.
Step 9  Implement           Execute tasks sequentially using `.speckit/prompts/implement.md`.
Step 10 Git Sync            Commit work safely using `.speckit/prompts/git_workflows.md`.
```

## The 7-Agent Mega Audit (Step 8 Protocol)

Before proceeding to Step 9, the AI agent MUST explicitly adopt these 7 personas to aggressively stress-test the Spec Kit:
1. **The Product Manager:** Audits feature viability, mobile responsiveness, and project scope.
2. **The DevOps Engineer:** Audits GitLab CI/CD, Dockerization, logging, and cold-start mitigations.
3. **The QA Lead:** Audits code formatting (`biome`, `prettier`), pre-commit hooks, and test frameworks.
4. **The Hackathon Judge:** Audits the "Wow Factor" and demo-ability (e.g., "Paste Demo URL" buttons).
5. **The UX/A11y Designer:** Audits Progressive Web App (PWA) compliance, ARIA states, and progressive loading UI.
6. **The Privacy Ethicist:** Audits PII scrubbing, `.gitignore` secret protection, and tracking risks (`youtube-nocookie`).
7. **The Doc Specialist:** Audits handoff metadata (`STRESS_TEST_CHECKPOINT.md`, `AGENTS.md`) and Changelogs.
