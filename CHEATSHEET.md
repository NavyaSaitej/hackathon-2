# Spec Kit — The AI Automation Cheatsheet

Welcome to the Spec Kit for AI, Data Analytics, and Telugu LLM development. This repository provides a rigorous, 10-step framework to govern autonomous AI agents and human developers alike.

## Initialization

To start a new project with this workflow:
1. Create your project directory.
2. Copy the `.speckit` folder into the project root.
3. Feed this `CHEATSHEET.md` to your AI agent.

## The 10-Step Autonomous Workflow

Agents and developers MUST follow this sequence strictly. Do not skip phases.

```text
Step 1  Initialize          Bootstrap environment and dependencies.
Step 2  Constitution        Load `.speckit/constitution.md` to establish non-negotiable operational mandates.
Step 3  Specify             Draft `.speckit/templates/specify.md` (Focus solely on WHAT & WHY).
Step 4  Clarify             Run `.speckit/prompts/clarify.md` to interactively resolve ambiguities in the Spec.
Step 5  Checklist           Run `.speckit/prompts/checklist.md` to unit-test the Requirements for quantifiable rigor.
Step 6  Plan                Draft `.speckit/templates/plan.md` (Define the Tech Blueprint & Architecture).
Step 7  Tasks               Draft `.speckit/templates/tasks.md` to break the plan into parallelizable tasks.
Step 8  Analyze             Run `.speckit/prompts/analyze.md` for a final cross-artifact consistency check.
Step 9  Implement           Execute tasks sequentially using `.speckit/prompts/implement.md`.
Step 10 Git Sync            Commit work safely using `.speckit/prompts/git_workflows.md`.
```

## Specialized Roles

Before engaging in specialized domain work, prime your agent with the appropriate identity:
- **Telugu NLP & LLM Focus:** Load `.speckit/prompts/telugu_llm_expert.md`

*(Failure to adhere to this workflow will result in misaligned implementations and violations of the project Constitution.)*
